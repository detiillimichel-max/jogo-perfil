# 🧩 Jogo Perfil - Clone Web

Uma versão digital e de código aberto inspirada no clássico jogo de tabuleiro **Perfil**, desenvolvido originalmente pela **Grow**. Este projeto foi feito puramente com tecnologias web integradas, rodando direto no navegador através do GitHub Pages.

## 🎮 Como Funciona o Jogo

O objetivo do jogo é adivinhar a identidade secreta da carta da vez (que pode ser uma **Pessoa**, **Lugar**, **Coisa** ou **Ano**) utilizando o menor número de pistas possível.

1. O jogo sorteia uma carta secreta e exibe a categoria na tela.
2. O jogador inicia a rodada com **20 pontos**.
3. A cada número de dica clicado, uma pista é revelada e o total de pontos **diminui em 1**.
4. O jogador pode digitar o seu palpite a qualquer momento:
   - **Se acertar:** Vence a rodada e garante os pontos restantes.
   - **Se errar:** O jogo avisa o erro para que novas dicas sejam abertas antes de um novo palpite.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído de forma simples e leve, sem dependência de frameworks externos:

- **HTML5:** Estrutura das caixas, botões e painel de exibição.
- **CSS3:** Estilização moderna com interface em Modo Escuro (*Dark Mode*) e posicionamento em *Grid*.
- **JavaScript (ES6):** Manipulação de eventos, lógica de decremento de pontuação, validação de strings e banco de dados simulado em estrutura JSON.

## 📦 Como Clonar e Executar Localmente

Se quiser baixar o código na sua máquina para estudar ou fazer modificações, siga os passos abaixo no terminal:

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd perfil-boardgame-clone
   ```
3. Abra o arquivo `index.html` em qualquer navegador de sua preferência (ou use a extensão *Live Server* no VS Code).
